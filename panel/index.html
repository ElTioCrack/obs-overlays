Conectar con GitHub

Para guardar desde la web, el panel necesita un token de tu cuenta. Se guarda solo en este navegador y solo se envía a GitHub.

  1. Abre GitHub → Fine-grained token.
  2. Repository access: Only select repositories → .
  3. Permissions → Repository → Contents: Read and write.
  4. Genera el token y pégalo aquí.
